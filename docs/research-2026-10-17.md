# Free-data and model research update

Release: `2026.10.17.2`. Evaluated October 16 Eastern / October 17 UTC.

## Sources and decisions

- [nflverse data schedule](https://nflreadr.nflverse.com/articles/nflverse_data_schedule.html)
  supplies statistics, schedules, rosters and depth charts. Keep these free
  sources; do not confuse roster activity with final participation.
- [Official NFL injury reports](https://www.nfl.com/injuries/league/2026/reg6)
  are directly readable without an API key. Match season, week, both clubs,
  displayed game date, player name and position. Verify the canonical URL and
  table schema. Exclude explicit negative designations, retain unknowns and
  practice information, and never clear an existing exclusion. The page supplies
  no publication timestamp: record observation time separately. Reports expire
  after 15 minutes. Missing, blank or conflicting records cannot imply health.
- [Haugh and Singal](https://www.columbia.edu/~mh2078/DFS_Revision_1_May2019.pdf)
  model DFS reward using opponents and payoffs, rather than treating projected
  points alone as profit. Ownership and payout coverage remain insufficient for
  a defensible expected-profit implementation. Do not invent these inputs.
- [Angelopoulos and Bates](https://arxiv.org/abs/2107.07511) explain held-out
  residual calibration and finite-sample order statistics. NFL observations are
  temporally dependent and changing roles violate simple exchangeability
  assumptions. Report measured coverage and interval scores without promising
  distribution-free coverage for this application.

## Mean prediction comparison

Both runs used exactly the same 20,205 historical records from public 2023–2026
statistics and the same chronological partitions. The final period contains
4,353 observations. Candidate ensemble weights were fixed at 25%, 50% or 75%
boosted-tree weight, paired with full-feature ridge at regularization 100.
Selection uses earlier expanding validation blocks only. Existing candidates
remain available. Shared fits are reused across ensemble candidates.

| Position | Prior RMSE | New RMSE | Selected model |
|---|---:|---:|---|
| DST | 5.317430 | 5.216979 | Ensemble |
| K | 4.882302 | 4.882302 | Ridge |
| QB | 8.487123 | 8.434406 | Ensemble |
| RB | 6.606680 | 6.606680 | Ridge |
| TE | 5.473113 | 5.458710 | Ensemble |
| WR | 6.492206 | 6.492206 | Ridge |

Combined RMSE fell from 6.361520 to 6.346057 (approximately 0.24%). The mean
squared-error improvement is 0.1965; a paired game-date bootstrap with 2,000
resamples gives a 95% interval of [-0.0080, 0.3929]. This interval crosses zero:
the incremental gain is small and not conclusive evidence of superiority.
This benchmark period has been used in earlier development; it is not a new
independent live evaluation. Updated files can change these results. The
production model is refitted on all available history, whereas diagnostics
freeze the fitted model before the chronological test.

## Uncertainty and downside

Choose equal-tail or absolute-residual interval shape using the final tuning
fold's proper interval score, calibrated from preceding tuning folds. Only
then use the separate calibration period for the residual distribution. The
80% interval score is width + 10 times each out-of-interval miss distance.
For absolute residuals, the radius is the ordered error at
ceil((n+1) * 0.8), capped at the available sample count.

Measured 80% coverage: DST 86.6%, K 71.3%, QB 77.1%, RB 82.4%, TE 79.2%,
WR 80.5%. These are estimates, not guarantees. Kicker undercoverage remains
material and is highlighted in the interface. Add mean width and proper
interval score so wider intervals cannot be advertised as an improvement merely
because they contain more outcomes.

Offensive scenario outcomes now retain negative scores from turnovers or
negative yardage. Kicker scores retain their zero lower bound under this
scoring system. Displayed model ranges also retain negative downside rather
than clipping all lower endpoints to zero.

## Accountability and reproduction

The evidence download records source URLs, observation clocks, data revision,
model members and weights, selected interval method, and measured errors.
Status and fitted-model caches carry an explicit release revision to prevent
mixing an older schema/model with a new interface after deployment.

For the historical comparison, call `prepare_history(datasets, cutoff)` once,
then `train_models(records, include_ensembles=False)` and
`train_models(records, include_ensembles=True)` with that same records table.
Compare `test_predictions` by player, position and game date. Do not vary the
protocol based on final test outcomes. Save pregame forecast audit downloads
and score them after games to collect new live evidence; corrected historical
boxes and selection into observed appearances remain limitations.
